# Dr. Welberth Fernandes de Souza

Site profissional e portal de conteúdo médico com foco em reumatologia.

## Stack

- Next.js
- React
- TypeScript
- App Router

## Estrutura inicial

- Home institucional
- Área de condições reumatológicas
- Biblioteca de artigos
- Apresentação profissional
- Bloco preparado para integração de agendamento
- Layout responsivo

## Desenvolvimento local

```bash
npm install
npm run dev
```

Acesse `http://localhost:3000`.
